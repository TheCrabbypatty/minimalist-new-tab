# Minimalist New Tab Page

A clean, distraction-free custom new tab page for Google Chrome. This project replaces the default new tab screen to remove corporate search suggestions, live typing predictions, and unwanted browser clutter while maintaining a sleek dark-mode aesthetic.

## Features

- **No Search Predictions:** Custom search input block with `autocomplete="off"` to stop intrusive search history tracking.
- **Minimalist Dark Theme:** Sleek dark background layout designed to reduce eye strain.
- **Custom Branding:** Features a personalized layout with custom hover button animations.

## How to Install and Run Locally

Because this is a custom open-source extension, you install it directly using Google Chrome's Developer Mode. Follow these simple steps:

### Step 1: Download the Code
1. Click the **Code** button at the top right of the repo
2. Make sure you select local.
2. Select **Download ZIP** from the dropdown menu.
3. Locate the downloaded file on your computer and extract (unzip) the folder.

### Step 2: Load into Google Chrome
1. Open Google Chrome and type `chrome://extensions/` into your address bar.
2. Look at the top-right corner of the Extensions page and turn the **Developer mode** toggle switch **ON**.
3. Click the **Load unpacked** button that appears in the top-left corner.
4. Select the extracted project folder (the folder containing the `manifest.json` file).

### Step 3: Activate Your New Tab
1. Open a brand-new tab in your browser.
2. Google Chrome will show a security prompt asking if you want to keep the change. Click **Keep changes**.
